Overpass API（施設検索）

Overpass API REST / POST 無料
概要
OpenStreetMap のデータベースに対して、独自のクエリ言語(Overpass QL)で施設やノードを検索するAPI。 OSM上のすべてのタグ情報（名前・種別・住所等）を対象に検索できる。
エンドポイント
POST https://overpass-api.de/api/interpreter
本システムでの使い方
1. 辞書マッチ検索 — OSMタグ（amenity, shop等）で施設を種別検索 + ラベル名で全タグ横断検索
2. 固有名詞検索 — [~"."~"keyword"] で全タグの値を正規表現マッチ
クエリ例: 辞書マッチ（セブンイレブン）
[out:json][timeout:10]; ( node[shop=convenience]["name"~"セブン"](around:250,35.57,139.66); way[shop=convenience]["name"~"セブン"](around:250,35.57,139.66); node["name"~"セブンイレブン|せぶんいれぶん|セブンイレブン",i](around:250,35.57,139.66); way["name"~"セブンイレブン|せぶんいれぶん|セブンイレブン",i](around:250,35.57,139.66); ); out center body;
クエリ例: 固有名詞（めんぱち）
[out:json][timeout:10]; ( node[~"."~"めんぱち|メンパチ",i](around:250,35.57,139.66); way[~"."~"めんぱち|メンパチ",i](around:250,35.57,139.66); relation[~"."~"めんぱち|メンパチ",i](around:250,35.57,139.66); ); out center body;
レスポンス形式
JSON (elements 配列) — 各要素に id, lat, lon, tags (name, amenity, shop等) を含む
レート制限: 公開サーバーのため、過剰なリクエストは制限される場合があります。 本システムではチャットメッセージ単位(1メッセージ=1〜3クエリ)で利用するため、通常は問題ありません。 タイムアウトは10秒に設定。

Nominatim API（地名検索・ジオコーディング）

Nominatim API REST / GET 無料
概要
OpenStreetMap のジオコーディング（地名検索）サービス。 テキストから地名・住所・施設名を解決し、緯度経度を返す。 内部に日本語の読み仮名辞書を保有しており、ひらがな入力から漢字地名を解決できる。
エンドポイント
GET https://nominatim.openstreetmap.org/search?q=...&format=json
本システムでの使い方
固有名詞検索時に Overpass API と並行実行。 Overpassがかな表記のタグ検索を行う一方、Nominatimは読み仮名→漢字地名の解決を担当。
  • むさしこすぎ → 武蔵小杉 を解決して座標を返す
  • しながわ → 品川 を解決して座標を返す
  • マンション名・施設名の読みにも対応
リクエスト例
GET https://nominatim.openstreetmap.org/search ?q=むさしこすぎ &format=json &limit=5 &viewbox=139.6,35.6,139.7,35.5 &bounded=1 &accept-language=ja
主要パラメータ
q — 検索テキスト
viewbox — 検索範囲の矩形 (西,北,東,南)
bounded=1 — viewbox内に限定
limit — 最大件数
レスポンス形式
JSON配列 — 各要素に place_id, lat, lon, display_name, type, class を含む
レート制限: 公開サーバーは最大1リクエスト/秒。 本システムでは固有名詞検索時に1名詞=1リクエストで利用。 大量の連続検索は避ける設計。

OpenStreetMap タイルサーバー（地図描画）

OSM Tile Server HTTP / GET 無料
概要
地図画像（タイル）を配信するサーバー。ズームレベルとXY座標に対応した256x256pxの画像を返す。 Leaflet が自動的にリクエストし、地図を描画する。
URL形式
https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
{s} = サブドメイン (a/b/c)、 {z} = ズームレベル (0-19)、 {x}/{y} = タイル座標
本システムでの使い方
Leaflet のベースレイヤーとして使用。マーカー・誤差円・検索範囲円はLeafletが地図上にオーバーレイ描画する。
利用ポリシー: OSM Tile Usage Policy に準拠。 重い用途(大量アクセス)の場合は自前のタイルサーバーを検討。

TinySegmenter（日本語形態素解析）

TinySegmenter クライアントサイド 無料
概要
約25KBの軽量な日本語形態素解析ライブラリ。サーバー通信なしでブラウザ内で完結する。 テキストを単語単位に分割し、固有名詞の抽出に利用。
CDN
https://cdn.jsdelivr.net/npm/tiny-segmenter@0.2.0/tiny_segmenter.js
本システムでの使い方
チャットテキストを形態素分割し、ストップワード（助詞・動詞等 約200語）を除去。 残った語を隣接結合して固有名詞を復元する。
  • 入力: 「めんぱちが見えます」
  • 分割: ["めんぱち", "が", "見え", "ます"]
  • ストップ除去: ["めんぱち"]
  • 出力: 固有名詞候補 "めんぱち"
特徴: 外部API呼び出しなし（オフライン動作可能）。 MeCab等と比較して精度は劣るが、ブラウザ完結でインストール不要。

Leaflet（地図UIライブラリ）

Leaflet v1.9.4 クライアントサイド 無料 / BSD-2
概要
オープンソースのJavaScript地図ライブラリ。タイルサーバーの画像を読み込み、マーカー・円・ポップアップ等のUI要素を地図上に描画する。
CDN
https://unpkg.com/leaflet@1.9.4/dist/leaflet.js https://unpkg.com/leaflet@1.9.4/dist/leaflet.css
本システムでの使い方
  • ベースマップ — OSMタイルの表示
  • 通報者マーカー — GPS位置のピン表示
  • 誤差円 — GPS精度の赤い破線円
  • 検索範囲円 — 誤差x5の黄色い破線円
  • ランキングピン — #1〜#5の番号付き丸ピン
  • ポップアップ — 施設名・スコア・OSMタグ情報の表示

データフロー

各APIがどのタイミングで呼ばれるかの全体像です。

タイミングAPI / サービス通信内容
ページ読み込み時 CDN (unpkg, jsdelivr) Leaflet, TinySegmenter のJSファイルをダウンロード
地図表示時 OSM タイルサーバー ズーム/スクロールに応じたタイル画像を取得
チャット(辞書マッチ)時 Overpass API タグ検索 + 全タグ横断検索を1クエリで実行
チャット(固有名詞)時 Overpass API + Nominatim 全タグ横断検索 + 地名ジオコーディングを並行実行
